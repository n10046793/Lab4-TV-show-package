# tvsummary (Lab 04)

Downloads TV show records from the TVMaze API and summarizes them by
genre, language rating and premiere decade. This is the Lab 03 package,
hardened: it now has a pytest suite, its own exceptions, logging,
type hints, ruff checks, and settings in a TOML file.

## Data source

https://api.tvmaze.com/shows?page=0 — one record is one TV show.
About 240 shows per run.
